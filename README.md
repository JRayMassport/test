# test

A minimal Python starter project.

## Overview

This repository currently contains a single entry-point script, `main.py`, which prints a greeting to standard output.

## Usage

Run the script directly with Python 3:

```bash
python3 main.py
```

Expected output:

```
Hello world!
```

## Reference

### `main.py`

| Function | Description |
| --- | --- |
| `main()` | Prints `Hello world!` to standard output. |

The script runs `main()` automatically when executed directly (`if __name__ == "__main__":`).
